# M0 demo: bootstrap

Prerequisites on a fresh Debian/Ubuntu machine: `sudo tools/setup-linux.sh`, Rust (rustup reads
`rust-toolchain.toml`), Node 22 and pnpm 10. Then `pnpm install`.

1. **Run the app**: `pnpm dev`. A window opens showing "Cadenza" with version, platform and build
   type. Those values come from the Rust core over Tauri IPC (`build_info` command), not from the UI.
   The font is the bundled Inter, and light/dark follows the system setting.
2. **Generate the test library**: `cargo xtask fixtures`. This writes ~150 files (~70 MB) to
   `fixtures-out/` in about 25 s, then runs the self-check. Expect
   `fixture check: 150 entries, 0 failures`, plus warnings about ffmpeg's own AAC end-trim handling.
   Things to look at:
   - `fixtures-out/manifest.json`: what every file must contain.
   - `fixtures-out/formats/`: every codec, bit depth and rate, including DSD64–DSD512.
   - `fixtures-out/tags/`: one richly tagged file per tag container.
   - `fixtures-out/library/`: a small realistic library (same-named albums, editions,
     a compilation, a classical work).
3. **Run all checks**: `cargo xtask ci`. This runs rustfmt, clippy (`-D warnings`), prettier,
   eslint, tsc, fixture regeneration + self-check, Rust tests and UI tests (~1 min with a warm
   cache).
4. **Build the packages**: `pnpm build`. Output goes to `target/release/bundle/deb/*.deb` and
   `target/release/bundle/appimage/*.AppImage`.
