# M4 demo: Tag editing

**Try this on a copy of some music first.** Cadenza never damages a file: every write is checked
before it replaces the original, and everything can be undone. But it's your music.

Set up: copy an album or two into a new folder and add it under Music Folders.

## 1. Edit one song
1. Right-click a song, then **Get Info…** (or play it and press Ctrl+I).
2. On Details, change the title. The changed field is outlined. Press **Save**. Expected:
   - "Saved 1 song" at the bottom, with **Undo**.
   - The new title shows everywhere: song list, album page, player bar.
3. Open another tagging program (Picard, Kid3, foobar2000 on another machine). It shows the new
   title, and every other tag as before.
4. Press Undo, or use Music Folders → Tag Changes → **Undo**. The old title is back.

## 2. Edit an album at once
1. Right-click an album, then **Get Info…**. Fields that differ between its songs show
   **Mixed**.
2. Set the genre to `Rock; Pop` (two genres) and save. Mixed fields, such as titles, are
   untouched.
3. Open **Table**: one row per song.
   - Click a title and use ↑/↓ and Enter to move.
   - Copy a column of titles from a spreadsheet and paste it into the first title: they fill
     down the rows.
   - **Number Tracks** numbers the songs 1, 2, 3… in order.
4. Open **Changes** before saving: every change, old value → new, each with Revert.

## 3. Actions
On the **Actions** tab (several songs open):
1. **Change Case** → Title Case on all text fields: "the man in the high castle" becomes "The
   Man in the High Castle". Words in the exceptions box (AC/DC, DJ…) keep their spelling.
2. **Find and Replace** with Regular expression on: find `^(\d+)\. ` and replace with nothing
   strips "01. " prefixes.
3. **Tags from File Names** with `%tracknumber% - %title%` fills titles and numbers from names
   like "03 - Song.flac". Names that don't match are left alone.
4. **Split** the artist at ` feat. `: "A feat. B" becomes two artists.
5. If any tag was saved in an old encoding (Russian or Japanese text showing as accented
   gibberish), **Fix Text Encoding** appears and repairs it.

Every action shows up under **Changes** first; Cancel → Discard throws them away.

## 4. Artwork
1. One song, **Artwork** tab: each embedded picture with its size. **Add Image…** adds one;
   change its type (Front Cover, Back Cover…) or remove it. Save.
2. An album, Artwork tab: **Set Cover for All…** puts one image on every song (their other
   pictures stay). **Remove All Artwork** clears them.
3. **Save Cover to Folder** writes cover.jpg beside the song; an existing file is never
   replaced.
4. Undo from Music Folders restores the old artwork.

## 5. Rename files from tags
1. An album, **File** tab, Rename Files from Tags. Choose a preset or write a pattern, e.g.
   `%albumartist%/[%year% - ]%album%/%tracknumber:2% %title%`, and press **Preview**.
   - Each file shows old → new. Files already named that way, and names that would collide,
     are marked and left alone.
2. **Move Files**. The files move inside the music folder (a .lrc beside a song goes with it),
   emptied folders are removed, and the songs keep their play counts and ratings.
3. Undo from Music Folders moves them back.

## 6. Ratings
1. On an album page, hover a song and click the stars. Clicking the same star again clears it.
2. Ratings stay in Cadenza unless you tick **Write ratings into the files too** (Music Folders).
   Then other players see them.

## 7. Safety
1. Make a file read-only (`chmod -w`) and edit it: the song is listed as not changed, with the
   reason; the file is untouched.
2. Tick **Keep a copy of each file before changing its tags** (Music Folders): copies go to
   Cadenza's data folder, under `backups/`.

## Automated checks
`cargo xtask ci` covers what needs no eyes:
- `core/tags/tests/write.rs`: every tag format round-trips an edit and its undo; every field at
  once; unknown frames, comments and atoms survive; pictures; refused edits leave files
  byte-identical; a process killed at each stage of a write never leaves a damaged file; a bad
  date frame from another tagger still reads and edits.
- `core/api/tests/api.rs`: edits reach files and the library (same track ids) and undo, with
  conflicts left alone; artwork changes and undo; the organiser keeps play counts and undoes;
  ratings in the library and in files.
- `ui/src/tagActions.test.ts`: every action.
